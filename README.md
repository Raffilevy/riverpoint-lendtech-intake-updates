# Riverpoint Lendtech Intake updates

Public Windows program downloads for Riverpoint Lendtech Intake.

Use the EXE attached to the [latest release](https://github.com/Raffilevy/riverpoint-lendtech-intake-updates/releases/latest).
Existing installations retain their saved connections and submission history.
First-time account connections are provided separately by your administrator.

Version 1.2.0 introduces automatic updates. Earlier versions require this version
to be installed once; later updates are downloaded and verified in the background.
The program waits until no deal is being reviewed or processed before replacing
itself and restarting. Updates do not change underwriting status or assignment.

This repository contains only public release metadata and program binaries.
Do not upload connection bundles, API keys, Gmail credentials, customer files,
submission journals, or coworker ZIP packages here. Application source is private.

The `latest.json` feed is published only after the release asset is available and
its public download has been verified against the manifest's SHA-256 and size.
